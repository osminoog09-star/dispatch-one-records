## Что Claude не должен ломать

- Не редактировать `docs/` руками: это результат `python server/export_static.py`.
- Не трогать Supabase JS и inline-логику в `tickets.html`, `staff.html`, `dictionaries.html`.
- Не переименовывать JS-зависимые классы: `sb-edit`, `sb-badge`, `sb-rank`, `sb-dept`, `nav-drop`, `nav-menu`, `admin-only`, `auth-slot`, `tk-*`, `dic-*`.
- Не менять backend/import/launcher/agent без отдельной задачи.

## Live-косяки, которые требуют отдельной задачи

- В `tickets.html` live-статусы показываются из Supabase как `open` / `closed`. Их надо переводить отображением (`Открыт` / `Закрыт`), но это inline JS, поэтому делать отдельным срезом с проверкой тикетов.
- В `staff.html` live-редактор на GitHub Pages подгружает звания/отделы из Supabase. Если в справочниках Supabase лежат английские названия, они снова появятся в селектах. Лучший путь: привести справочники к русским названиям через админку или добавить отдельный display-mapping в JS без изменения id.
- Мусорные пользовательские заголовки тикетов вроде крика капсом надо не только обрезать CSS, но и нормализовать при создании тикета в лаунчере/поддержке.
