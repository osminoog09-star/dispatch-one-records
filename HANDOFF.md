## Что это

Сайт-реестр для GTA V LSPDFR: аресты, штрафы, суды, смены, личный состав, карта. Данные —
реальные из игры (pdComp + плагин `DispatchOne.MDT` → агент `pdcomp_sync` → шлюз/inbox → сайт).
Flask-шаблоны экспортируются в `docs/` и раздаются GitHub Pages. Живая часть (вход, тикеты,
звания, модерация, роли) — Supabase.

- Сайт: https://osminoog09-star.github.io/dispatch-one-records/
- Рабочая ветка `main`, автосборка каждые 30 минут (`.github/workflows/build-site.yml`).

  Проверено в бою на 7-ADAM-20.

- **Поддержка**: тикеты с сайта и из лаунчера в одной очереди + rule-based диагностика логов.
- **Лаунчер 1.4.16 / агент 1.1.2**: разделы, инструкция, онбординг, вход через Discord,
  onedir-сборка (без ошибки Python DLL), авто-поиск игры/Vinewood/pdComp.

## Грабли (на них уже обожглись — не повторять)

1. **Один источник званий/отделов — Supabase.** Раньше они были и в SQLite, и в Supabase, и
   разошлись: главная показывала «Detective I», админка — «Sergeant II». Теперь везде
   плейсхолдер `.sb-rankdept[data-cs]`, скрипт в конце `base.html`.
   **Не возвращать `rank_label`/`department_label` в шаблоны** — `qa_check.py` это ловит.
2. **Вызовы — это зеркала задержаний** (`external_id LIKE 'case-callout:%'`), настоящих нет.
   Они нужны только журналу `/callouts`. Рядом с арестами их показывать нельзя — будет
   двоение (уже было в личных делах, у офицера и в счётчиках). Флаг `real_only`.
3. **Плагин LSPDFR** наследуется от `LSPD_First_Response.Mod.API.Plugin` + атрибут
   `[assembly: Rage.Attributes.Plugin(...)]`. От `Rage.Plugin` наследоваться НЕЛЬЗЯ (он `sealed`
   → плагин молча не грузится). `Assembly.Location` пуст — путь брать от `Directory.GetCurrentDirectory()`.
4. **Пути у игроков разные.** Жёсткий `C:\Program Files\...` ломал сбор данных у тех, у кого
   игра на другом диске (Steam на `F:`) — всё ищем автопоиском.
5. **Два агента в одной папке затирают друг друга.** Никаких `git reset --hard`, `git checkout .`,
   `git stash`, `git add -A` — только свои файлы явными путями.
6. **`docs/` руками не править** — только `python server/export_static.py`.

## Проверка одной командой

```powershell
py server/qa_check.py
```

Гоняет: все маршруты (включая каждое дело/офицера/досье), битые ссылки и мусор в `docs/`,
дубли и сирот в базе, отсутствие второго источника званий, живость Supabase. Код 1 при провале.
Обычная проверка «страница отдаёт 200» рассогласование данных не ловит — этим уже ловили баг.

