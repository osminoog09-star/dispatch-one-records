# Dispatch One — AI-диспетчер полиции для GTA V

> Рабочее имя: **Dispatch One** (позывной «Air-1»). Язык: русский на старте, английский позже (архитектура i18n-ready).


Конкурент Vinewood Hub. AI-диспетчер, который слушает голос офицера, отвечает живым
голосом по-русски и управляет миром игры (подкрепление, погони, пробив и т.д.).

**Отличия от конкурента:** память смены, сменный «мозг» (Gemini ↔ своя LLM),
открытость/локальный режим без подписки, два фронта (LSPDFR + FiveM) из одного мозга.

**Статус:** проектирование на бумаге завершено. Кода пока нет (бюджет $0 —
разработка бесплатна: бэкенд на localhost + Gemini free-tier).

## Дорожная карта

```
Фаза 0 — Бэкенд-«мозг» (Python, localhost на старте)         [спроектировано]
Фаза 1 — Фронт LSPDFR (одиночка, C# DLL)                     [спроектировано]
Фаза 2 — Фронт FiveM (свой сервер → продукт)                 [черновик]
Фаза 3 — Локальный режим + продуктизация/подписка            [спроектировано]
```

## Что нужно перед кодом (не блокеры бумаги)
```
- Свой Gemini API-ключ (free-tier из Google AI Studio) — к вехе 4.
- Фреймворк FiveM-сервера (ESX/QBCore/кастом) — к Фазе 2.
- Модель видеокарты — для оценки локального режима.
```
