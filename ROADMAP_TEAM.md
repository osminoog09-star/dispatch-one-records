## 2. Жёсткие правила против затирания (обязательно обоим)

1. **НИКОГДА** не запускать `git reset --hard`, `git checkout -- .`, `git checkout .`,
   `git stash` на всём дереве, пока второй агент может иметь несохранённые файлы.
   Это стирает чужую работу. Если нужно откатить — откатывай ТОЧЕЧНО свой файл по пути.
2. Стейджить только свои файлы явными путями: `git add server/app/...`. **Не** `git add -A`,
   **не** `git add .` — иначе заберёшь чужие незакоммиченные правки.
3. Коммитить маленькими срезами и часто. Не держать большие несохранённые изменения.
4. Перед push: `git pull --rebase origin main`. Конфликты в `docs/` решать так:
   взять исходники, заново `python server/export_static.py`, пересобрать `docs/`.
5. `docs/` руками не редактировать — только через `export_static.py`.
6. Если берёшь задачу — сначала запиши в `WIP.md` (`IN PROGRESS дата Автор: …`).
   Если задача уже `IN PROGRESS` у другого — не брать.
