# Dispatch One — sync-агент

Читает данные твоего игрового MDT **pdComp** (аресты, судебные дела) и отправляет на сайт.
Только реальные данные из игры — ничего выдуманного.

## Как запустить

1. Убедись, что **сайт запущен** (локально: `http://localhost:8000`).
2. Дважды кликни **`start-agent.bat`**.
3. Оставь окно открытым во время игры — агент сам подхватывает новые аресты и дела.

Готово. Никаких установок пакетов не нужно — агент работает на стандартном Python.

## Что синхронизируется

| Файл pdComp | Куда на сайте |
|---|---|
| `arrests.json` | Дела (протоколы ареста) |
| `cases.json` | Судебный реестр |

Дубли не создаются (сверка по ID из игры). Адреса с побитой кириллицей чинятся автоматически.

## Настройки (по желанию)

Переменные окружения:
- `SITE_URL` — адрес сайта (по умолчанию `http://localhost:8000`). Для внешнего сайта впиши в `start-agent.bat`.
- `RECORDS_API_KEY` — ключ авторизации (по умолчанию `dev-key`, должен совпадать с сайтом).
- `POLL_SECONDS` — как часто проверять файлы (по умолчанию 8 сек).
- `PDCOMP_STORE` — путь к папке данных pdComp (по умолчанию стандартный путь GTA V Legacy).

## Требования

Обычный **Python** (python.org или из «Python install manager»), запускаемый командой `py`.
Python из Microsoft Store **не подойдёт** — он в песочнице и не видит папку игры.
