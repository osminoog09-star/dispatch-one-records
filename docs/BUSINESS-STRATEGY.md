# Бизнес-стратегия: монетизация, тарифы, выход на рынок

**Назначение:** как продукт зарабатывает и как до людей доходит. На реальных цифрах COGS.

---

## 1. Тарифы (три уровня)

| Тариф | Что даёт | Мозг | Кто платит за AI | Наш расход | Цена (гипотеза) |
|---|---|---|---|---|---|
| **Local / BYO-key** | Полный плагин, память смены | Свой ключ Google ИЛИ локальный (Whisper+Ollama+Edge-TTS) | Пользователь (или никто — локально) | ~$0 | Бесплатно или разовая покупка плагина |
| **Cloud** | Всё + наш облачный мозг «под ключ» | Наш Gemini/Edge-TTS пул | Мы | ~$0.2–0.5/час игры | Подписка ~$X/мес с лимитом минут |
| **FiveM Server** | Диспетчер на сервер, мультиигрок, память смены сервера | Наш облачный/GPU | Мы | зависит от онлайна | Подписка на сервер / per-slot |

**Ключевая идея:** «Local/BYO-key» подрывает платных конкурентов (даём бесплатно то, за что
Vinewood берёт подписку), а зарабатываем на удобстве облака и на **FiveM** (там реальная ценность
и мало конкурентов).

---

## 2. Юнит-экономика (Cloud-тариф)

```
Расход на игрока (Gemini Live): ~$0.22–0.57 / час игры.
Снижение: Edge-TTS (бесплатный TTS) вместо Gemini-out → режем выходной звук почти в ноль,
          остаётся только вход+LLM. Потенциально ~$0.10–0.25/час.
Игрок 20 ч/мес: ~$2–11 COGS (без Edge-TTS) → ~$2–5 (с Edge-TTS).

Вывод по подписке:
  - С лимитом минут и Edge-TTS маржа положительная при цене ~$6–10/мес.
  - Без лимитов тяжёлый игрок съедает маржу → ОБЯЗАТЕЛЬНО кап минут/мес на тариф.
  - «BYO-key» тариф вообще без нашего COGS — самый безопасный.
```

> Точные цены выставить после замера реального потребления на тестах (веха 4-8).

## 3. Рычаги снижения себестоимости

```
1. Edge-TTS (Microsoft, бесплатно, русские нейроголоса) вместо платного Gemini-out.
   → Гибрид: Gemini/локальный STT+LLM + Edge-TTS голос. Проверено конкурентом.
2. VAD-гейт (Silero) — не гнать тишину в облако.
3. Кап минут на тариф + таймаут простоя сессии.
4. Локальный режим для тех, у кого есть железо — ноль COGS.
5. Свой GPU — только когда стабильная нагрузка оправдает (не раньше).
```

## 4. Выход на рынок (Go-to-market)

| Канал | Зачем |
|---|---|
| **LCPDFR.com** | Главная площадка LSPDFR-сообщества. Публикация бесплатного плагина = охват + репутация. |
| **YouTube (LSPDFR-креаторы)** | Демо «поговори с диспетчером» вирусится. Дать мод креаторам заранее. |
| **Discord (RU + EN GTA/LSPDFR/FiveM)** | Прямая аудитория, обратная связь, ранние тестеры. |
| **FiveM-сообщества** | Прямой выход на владельцев RP-серверов — платящие клиенты Фазы 2. |

**Тактика запуска:**
```
1. Бесплатный LSPDFR-плагин (Local/BYO-key) на LCPDFR → репутация и юзербаза.
2. Демо-видео с памятью смены (то, чего нет у других) → отличие видно сразу.
3. FiveM-версия для своего сервера → кейс → продажа другим серверам.
4. Облачная подписка как удобная опция для тех, кто не хочет возиться с ключами.
```

## 6. Этапы монетизации (совпадают с фазами)

```
Фаза 1 (LSPDFR): бесплатный плагин → аудитория и отзывы. Денег не просим.
Фаза 2 (FiveM, свой сервер): кейс + первые платящие серверы.
Фаза 3: облачная подписка + локальный режим как отличие + масштабирование.
```
