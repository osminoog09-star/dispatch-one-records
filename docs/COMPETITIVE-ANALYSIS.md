## 2. Наш клин (чего нет ни у кого РАЗОМ)

```
1. ПАМЯТЬ СМЕНЫ — сквозная линия, ссылки на прошлые вызовы. Нет ни у кого.
2. ДВА ФРОНТА из одного мозга — LSPDFR (одиночка) + FiveM (мультиплеер).
   Конкуренты только одиночка. FiveM-диспетчер с AI — почти пустая ниша.
3. СМЕННЫЙ МОЗГ — Gemini ИЛИ локальный (Whisper+Ollama) ИЛИ Edge-TTS.
   Не заперты в вендоре. Гибкость по цене/приватности.
4. ЛОКАЛЬНЫЙ/ОТКРЫТЫЙ РЕЖИМ — свой ключ или своё железо, без вечной подписки.
5. РУССКИЙ как родной + перспектива EN. Vinewood — RU, но закрытый и платный.
```

Ни один конкурент не закрывает все пять. Vinewood ближе всех, но проигрывает по 1-5.

---

## 3. Позиционирование

> «AI-диспетчер, который помнит твою смену, работает и в одиночке, и на сервере с
> коллективом, и не требует вечной подписки — крути в облаке или на своём железе».

- Против **Vinewood**: открытость + память + FiveM + не платишь за минуты.
- Против **AIDispatch (PR)**: не привязаны к одному моду, память смены, RU + FiveM.
- Против **бесплатных**: реально управляем миром (не только голос) + память + мультиплеер.

---

## 4. Риск-реальность

```
- Рынок уже занят несколькими игроками → «клон Vinewood» не взлетит, нужен острый клин.
- Есть БЕСПЛАТНЫЕ конкуренты → платная подписка должна давать явно больше (FiveM,
  память, локальный режим), иначе уйдут к бесплатным.
- FiveM-ниша — наименее занятая → это наш главный стратегический вход, а не одиночка.
```

**Вывод:** одиночка LSPDFR (Фаза 1) — это витрина и полигон, чтобы отточить мозг.
Реальный рыночный вход и отличие — **FiveM с памятью смены сервера** (Фаза 2), где
конкурентов почти нет.

Источники: [AIDispatch for PR](https://www.lcpdfr.com/downloads/gta5mods/scripts/54324-aidispatch-for-policing-redefined/), [AI Dispatcher](https://www.lcpdfr.com/downloads/gta5mods/scripts/54323-ai-dispatcher/), [Polish Dispatch](https://www.lcpdfr.com/downloads/gta5mods/audio/54506-polish-dispatch-v08-beta-ai/).
```
