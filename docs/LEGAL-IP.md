# Юридика и права (IP) — что можно и нельзя шипить

**Назначение:** избежать главного риска продукта — конфликта из-за прав на чужие моды.
**Статус:** анализ на бумаге. Не юридическая консультация; при коммерциализации — проверить с юристом.

---

## 1. Суть риска

Модель Vinewood включает раздачу **20-ГБ сборки из десятков чужих модов** (PolicingRedefined,
RiskierTrafficStops, callout-паки и т.д.). Сообщество **LCPDFR.com прямо запрещает
редистрибуцию** чужих модов и банит за неё. Vinewood либо договорился с авторами, либо
в серой зоне (частая практика в RU-сегменте).

**Если мы копируем их модель раздачи сборки — наследуем этот риск.**

---

## 2. Наша безопасная модель: шипим ТОЛЬКО свой плагин

```
ШИПИМ (наше, 100% наши права):
  ✔ Плагин-диспетчер (LSPDFR DLL / FiveM resource)
  ✔ Наш бэкенд-«мозг»
  ✔ Наш системный промпт, персонажи, аудио-ассеты (свои записи/сгенерированные)

НЕ ШИПИМ (чужое):
  ✘ Чужие моды (PR, callout-паки, графика) — на них ссылаемся, не раздаём
  ✘ Готовую 20-ГБ сборку

ВМЕСТО раздачи сборки:
  → Список зависимостей + ссылки на официальные страницы модов (пусть юзер сам
    скачает с LCPDFR/автора). Наш плагин ИНТЕГРИРУЕТСЯ с ними по рефлексии, если стоят.
  → Опц. лаунчер лишь ПОМОГАЕТ скачать с официальных источников, не хостит чужое.
```

Так работают легальные менеджеры модов: они оркестрируют установку, но не редистрибутят.

---

## 3. Интеграция без жёсткой зависимости

- Плагин цепляется к PolicingRedefined / GrammarPolice / CommonDataFramework / ImmersiveAmbientEvents
  **по рефлексии в рантайме** (как конкурент): «если мод загружен — используем, нет — работаем без него».
- Значит мы **не линкуем и не распространяем** их сборки на этапе компиляции — только опционально
  дружим с тем, что уже стоит у юзера. Это чисто с точки зрения прав.

## 4. Платформенные правила

| Площадка | Что учесть |
|---|---|
| **LCPDFR.com** | Правила редистрибуции строгие. Свой плагин публиковать можно; чужое в комплекте — нет. Читать их Terms перед публикацией. |
| **Rockstar/GTA** | Моды только для **одиночной** GTA V (наш LSPDFR-фронт — ок). Онлайн R* запрещает — FiveM это ОТДЕЛЬНЫЙ мультиплеер, не GTA Online (легитимен как своя платформа). |
| **FiveM (CFX)** | Свои правила по ресурсам/платному контенту (escrow, Tebex). Изучить перед продажей ресурса. |
| **Gemini API** | Google ToS: не проксировать чужим пользователям в нарушение квот/условий. Для «BYO-key» — юзер сам принимает ToS Google. |

---

## 5. Влияние на монетизацию

```
- Продаём СВОЙ софт/сервис (диспетчер, мозг, подписку на облачный мозг),
  а не чужой контент. Это чистая позиция.
- Тариф «BYO-key» (юзер на своём ключе Google) снимает с нас и расходы, и часть
  ответственности за проксирование.
- Никакой раздачи чужих 20 ГБ → нет CDN-риска и нет прав-риска разом.
```
