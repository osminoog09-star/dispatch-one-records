# Локальный режим — бесплатный мозг (спецификация)

**Назначение:** альтернатива Gemini — весь тракт на своём железе, ноль стоимости за минуту.
**Статус:** Фаза 3 (после того, как облачный вариант доказал играбельность). Реализует тот же `IBrain`.
**Наше отличие:** у конкурента этого нет вообще (он только облако).

---

## 1. Каскад (вместо voice-to-voice одной моделью)

```
Микрофон (PCM 16кГц)
   │
   ├─► VAD (Silero) — режет тишину, ловит начало/конец речи
   │
   ├─► STT: Whisper (faster-whisper) — русский текст
   │
   ├─► LLM: локальная модель — реплика + команды-токены
   │        (тот же системный промпт, что в облаке)
   │
   └─► TTS: русский синтез — голос диспетчера (PCM) → в игру
```

Наружу — тот же интерфейс `BrainSession` (send_audio / on_audio_out / on_tool_call),
что и у `GeminiBrain`. Переключение — `BRAIN=local` в конфиге.

---

## 2. Компоненты и выбор

| Звено | Вариант | VRAM | Заметки |
|---|---|---|---|
| **VAD** | Silero VAD | ~0 | Лёгкий, уже используем на гейте. |
| **STT** | faster-whisper `small`/`medium` | ~1-2 ГБ | Русский отлично. `small` быстрее, `medium` точнее. |
| **LLM** | Qwen2.5-7B-Instruct (Q4) | ~5-6 ГБ | Узкая задача → 7B хватает. Возможен 3B для слабых карт. |
| **TTS** | Silero TTS (ru) / XTTS-v2 / F5-TTS | ~1-2 ГБ | **Слабое звено по выразительности** — слушать и выбирать. |

**Раннеры:** LLM через Ollama или llama.cpp (server-режим); Whisper через faster-whisper;
TTS — своя обёртка. Всё Python-нативно → ложится в тот же бэкенд.

---

## 3. Дообучение LLM (опц., «своя ЛЛМ» в реальном смысле)

- НЕ обучение с нуля. Берём открытую 7B и **LoRA-дообучаем** на диалогах диспетчера.
- Датасет: пары «реплика офицера + контекст → ответ диспетчера + токены», сгенерированные
  из нашего промпта (можно сначала облаком Gemini/Claude нагенерить примеры — разово).
- Результат: маленькая быстрая модель, заточенная ровно под рацию, часто ЛУЧШЕ большой
  универсальной на этой узкой задаче.

---

## 4. Задержка и железо (честно)

- Каскад добавляет задержку на каждом звене (STT + LLM + TTS последовательно).
  На хорошей карте — ~1-2 сек до начала ответа. Для рации терпимо (там паузы естественны).
- **Главное ограничение — VRAM рядом с игрой.** Модовая GTA сама ест 8-12 ГБ.
  - Карта 24 ГБ (4090) → весь стек влезает рядом с игрой.
  - Карта 8-12 ГБ → одновременно не влезет: LLM на CPU (медленнее), или на 2-й машине
    по локальной сети, или в облаке держать только TTS.

## 5. Где локальный режим выигрывает

```
+ Ноль стоимости за минуту (только электричество).
+ Приватность — ничего не уходит в облако.
+ Работает офлайн.
+ Для продукта: «локальный режим» = киллер-фича против облачной подписки конкурента.
- Ниже выразительность голоса (TTS).
- Требует мощной карты рядом с игрой.
- Задержка чуть выше voice-to-voice.
```

**Стратегия:** облако (Gemini) — база и старт; локальный режим — опция для тех, у кого
есть железо, и как отличие продукта. Оба — за одним интерфейсом `IBrain`.
