## 2. Журнал решений (что и почему выбрано)

| Решение | Выбор | Почему |
|---|---|---|
| Архитектура | Один бэкенд-мозг, два фронта | Переиспользование мозга; чище, чем у конкурента (клиент-онли). |
| Язык бэкенда | Python (FastAPI) | AI-экосистема (Whisper/Ollama/TTS) нативна; не переписывать при локальном режиме. |
| Мозг | Абстракция IBrain, сменный | Не запираться в Gemini; старт облако → локальный/Edge-TTS. |
| Команды | Парсинг текст-токенов, НЕ нативный function-calling | Проще/надёжнее в Live API; конкурент выбрал так же. |
| Голос (цена) | Гибрид: STT+LLM + Edge-TTS | Edge-TTS бесплатный и качественный RU → режет COGS. |
| Первый фронт | LSPDFR (одиночка) | Нет войс-инъекции и фреймворков → быстрее до «работает». Полигон для мозга. |
| Рыночный вход | FiveM (Фаза 2) | Там мало конкурентов; одиночка — витрина. |
| Раздача модов | НЕ раздаём чужое, только ссылки | Снимает права-риск и CDN-расход разом. |
| Хостинг мозга | Старт localhost, потом облако pay-per-use | $0 на разработке; свой GPU — только при нагрузке. |
| Стартовый тариф | Бесплатный Local/BYO-key на LCPDFR | Подрыв платных конкурентов + быстрый охват. |
| Отличие №1 | Память смены | Ни у кого нет; видно в демо сразу. |
