# Шлюз приёма данных — как развернуть (бесплатно, ~10 минут)

Зачем: чтобы GitHub-токен **не лежал в лаунчере**. Данные пойдут через Cloudflare Worker,
а он уже своим секретным токеном пишет в репозиторий. Даже если кто-то вскроет .exe —
токена там нет. Бесплатно, работает 24/7 без твоего ПК.

---

## Шаг 1. Регистрация на Cloudflare (5 мин)
1. Открой **https://dash.cloudflare.com/sign-up**
2. Заведи аккаунт (почта + пароль), подтверди почту.
3. Тариф — **бесплатный** (Workers free: 100 000 запросов в день, нам хватит с запасом).

## Шаг 2. Создать Worker (2 мин)
1. В панели слева: **Workers & Pages** → **Create** → **Create Worker**.
2. Имя: например `lapd-gateway` → **Deploy** (создастся с примером).
3. Нажми **Edit code**.
4. Удали весь пример, вставь содержимое файла **`worker.js`** (лежит рядом с этой инструкцией).
5. **Deploy** (кнопка справа вверху).

## Шаг 3. Задать секреты (3 мин)
В Worker: **Settings** → **Variables and Secrets** → добавь три штуки (тип **Secret**):

| Имя | Значение |
|---|---|
| `GITHUB_TOKEN` | твой fine-grained токен (Contents: Read and write на репозиторий) |
| `GITHUB_REPO` | `osminoog09-star/dispatch-one-records` |
| `SHARED_KEY` | придумай пароль (например 16 случайных символов) — его вставим в лаунчер |

Сохрани → **Deploy**.

## Шаг 4. Дать мне два значения
После деплоя у Worker будет адрес вида:
```
https://lapd-gateway.ТВОЙ-АккаунтName.workers.dev
```
Пришли мне **этот адрес** и **SHARED_KEY**. Я пересоберу лаунчер так, чтобы он слал данные
на шлюз (без токена внутри), и обновлю на сайте.

---

## Что изменится
- **До:** токен вшит в лаунчер → вскрыл .exe → получил доступ к репозиторию.
- **После:** в лаунчере только адрес шлюза и общий ключ. Шлюз проверяет ключ, режет спам
  (не чаще раза в 10 сек с позывного) и сам пишет в GitHub секретным токеном.
- Если ключ утечёт — меняешь `SHARED_KEY` в Cloudflare, пересобираешь лаунчер. GitHub-токен
  при этом не светится вообще.
