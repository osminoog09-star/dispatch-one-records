# Деплой сайта Records (чтобы был доступен другим)

Локально сайт работает на `http://localhost:8000`. Чтобы к нему могли заходить другие игроки
и агент слал данные извне — нужен публичный хостинг с Python.

## Рекомендация: Render (бесплатный тариф)

Почему Render: бесплатный веб-сервис с Python, деплой прямо из GitHub, публичный HTTPS-адрес.

### Шаги

1. **Выложи код на GitHub** (если ещё нет): создай репозиторий, запушь папку `AIDispatcher`.
2. Зайди на **render.com** → зарегистрируйся (можно через GitHub).
3. **New → Web Service** → подключи свой репозиторий.
4. Настройки сервиса:
   - **Root Directory:** `server`
   - **Runtime:** Python
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `gunicorn "app.main:app" -b 0.0.0.0:$PORT -w 2 --timeout 60`
5. **Environment (переменные окружения):**
   - `RECORDS_API_KEY` = придумай длинный секретный ключ (НЕ `dev-key`)
   - `COMMUNITY_NAME` = `LAPD` (или как назовёшь)
   - `OFFICER_NAME` = `Denis Sherman` (по желанию)
   - `DISCORD_WEBHOOK_URL` = когда будет webhook
6. **Create Web Service** → через пару минут получишь адрес вида `https://твой-сервис.onrender.com`.

### Подключить агента к хостингу

В `agent\start-agent.bat` впиши свой адрес и тот же ключ:
```
set SITE_URL=https://твой-сервис.onrender.com
set RECORDS_API_KEY=твой-секретный-ключ
```
Теперь агент шлёт данные на публичный сайт, и другие игроки тоже могут ставить агента и слать туда.

## Важные оговорки (честно)

- **База данных SQLite на бесплатном Render — временная**: при передеплое/перезапуске данные
  могут сбрасываться. Для постоянного хранения позже подключим PostgreSQL (у Render есть
  бесплатная база) или платный диск. Для старта и тестов — ок.
- **Скриншоты** тоже хранятся на диске сервиса — временные на бесплатном тарифе.
- **Бесплатный сервис засыпает** при простое (первый заход после паузы — медленный старт ~30 сек).
- **Ключ API** держи в секрете (переменная окружения, не в коде).

## Альтернативы

- **Railway**, **PythonAnywhere**, **Fly.io** — тоже бесплатные тарифы, шаги похожи.
- **Свой VPS** — когда пойдёт стабильная нагрузка (постоянная работа, своя БД).
