# Ключ доступа для игроков — как создать (один раз)

Чтобы агенты игроков могли отправлять данные на сайт, нужен **ключ доступа GitHub**.
Создаётся один раз, вписывается игрокам в установщик. Хостинг не нужен — GitHub всё делает сам.

## Как создать (2 минуты)

1. Открой: **https://github.com/settings/personal-access-tokens/new**
   (или: GitHub → аватар справа вверху → Settings → Developer settings →
   Personal access tokens → **Fine-grained tokens** → Generate new token)

2. Заполни:
   - **Token name**: `LAPD Records — агенты игроков`
   - **Expiration**: `No expiration` (или год — потом придётся обновлять)
   - **Repository access**: выбери **Only select repositories** →
     отметь **`dispatch-one-records`**

3. Раздел **Repository permissions** → найди **Contents** →
   поставь **Read and write**
   *(это единственное нужное право — доступ только к одному репозиторию)*

4. Внизу — **Generate token** → скопируй ключ (`github_pat_...`).
   ⚠️ Он показывается один раз — сохрани.

## Что дальше

Этот ключ ты выдаёшь игрокам. Они вставляют его в установщик в поле
**«Ключ доступа»** — и всё, их аресты, штрафы и суды сами появляются на сайте.

## Как это работает

```
Игрок поиграл → закрыл игру
   ↓ агент кладёт его записи в GitHub (по ключу)
GitHub сам принимает и пересобирает сайт (сразу и каждые 30 минут)
   ↓
Сайт обновлён — твой компьютер может быть выключен
```

## Безопасность

- Ключ даёт доступ **только к репозиторию `dispatch-one-records`**, к остальным твоим
  репозиториям — нет.
- Если ключ утечёт или кто-то начнёт слать мусор — просто **удали его** на той же
  странице настроек и выдай новый. Сайт при этом не пострадает.
- Не выкладывай ключ публично — давай лично проверенным людям в LAPD.

## Проверка

Отправку и приём я уже проверил вживую: тестовая запись игрока `1-ADAM-13` прошла путь
«агент → GitHub → сайт» и появилась в списке задержаний автоматически.
